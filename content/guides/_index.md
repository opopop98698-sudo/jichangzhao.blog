## 一、网络加速服务核心技术术语与运作机制

为了摆脱操作困惑，新手必须理解现代网络代理的核心术语：

### 1.1 核心操作术语释义

- **订阅链接（Subscription URL）**：服务商生成的一串专属网络地址（通常为 HTTPS 链接）。客户端通过访问该链接，能够批量下载数十个甚至上百个节点的服务器 IP、端口、加密协议与密钥，并支持定时自动静默更新。
- **Base64 编码（Base64 Encoding）**：一种用于在网络上安全传输二进制数据的常见编码格式。订阅链接返回的内容通常是一长串经过 Base64 编码的文本，客户端解码后即可提取出节点配置。
- **分流规则组（Routing Rules）**：客户端内置的智能交通指挥系统。通过内置的域名列表（如 GeoSite）与 IP 归属地数据库（如 GeoIP），自动将访问百度、淘宝、微信的国内请求直连本地网络，仅将 Google、ChatGPT、YouTube 的请求导向境外专线。
- **本地混合监听端口（Mixed / Socks5 Port）**：客户端在本地电脑上开放的内部代理接口（常见为 `127.0.0.1:7890`）。普通第三方软件（如浏览器插件、终端 Git）只需填入该端口，即可借由客户端的代理通道通信。
- **TUN 虚拟网卡（TUN Interface）**：在系统内核层面创建的虚拟以太网卡，能够无死角接管整机所有软件（包括命令行、游戏客户端）的 TCP 和 UDP 数据包，彻底摆脱传统系统代理易漏包的缺陷。

## 四、客户端智能分流原理与 DNS 泄漏防范深度解析

为什么很多新手配置完代理后，国内网站变慢甚至无法加载，或者海外网站提示无法访问？核心在于分流与 DNS 机制：

### 4.1 传统系统代理的弊端与 DNS 污染
在默认的系统代理模式下，当你在浏览器输入 `www.google.com` 时，系统首先需要向你本地运营商的 DNS 服务器发起域名解析请求。由于众所周知的公网 DNS 污染，本地 DNS 会返回一个错误的假 IP 地址，导致客户端拿着假 IP 无法完成连接。

### 4.2 现代客户端的 Fake-IP 智能分流黑科技
以 Clash Verge Rev（基于 Mihomo 内核）为代表的现代客户端，全面采用了 **Fake-IP 模式**：
1. 当任何软件发起域名解析时，客户端本地代理内核会立即拦截该请求，并瞬间返回一个预留的假 IP（如 `198.18.0.x`）；
2. 软件拿到假 IP 后，立刻向本地代理内核发起 TCP 握手数据包；
3. 代理内核在内存路由表中将该假 IP 重新映射回真实的原始域名（`www.google.com`），并通过加密的 IEPL/IPLC 专线隧道直接发往境外的落地服务器；
4. 落地服务器直接在境外洁净网络完成真实的 DNS 解析并获取数据返回。**全程完全绕过了本地 DNS 解析，从物理层面彻底根除了 DNS 污染与 DNS 泄漏风险**。

## 五、新手首单防踩坑核心法则

### 5.1 坚决坚持「首月月付」
无论某个品牌在各大论坛、群组被吹捧得多么神乎其神，每个用户家里的本地宽带（电信/联通/移动/广电）、地理省份以及路由器网络环境都是千差万别的。首月花费 5~25 元订阅一个月付套餐，连续测试其在晚高峰 20:00 - 23:30 的测速带宽、网页加载延迟与流媒体播放表现，是保护个人资金安全的底线。

### 5.2 收藏官方「防失联发布页」
服务商的主站域名随时可能遭受公网 DNS 污染。在注册成功的当天，务必登录官网用户后台，找到官方公告中的「永久发布页」或「防失联导航链接」，将其直接添加到浏览器的书签栏。一旦日后主域名无法访问，只需打开发布页即可获取最新的可用登录镜像。

## 七、常见问题 FAQ（新手配置与选购实操大百科）

### Q1: 刚买的订阅链接导入客户端后，节点全部显示「Timeout」或红色感叹号怎么排查？
**A**: 请按照以下标准顺序排查：
1. **校准系统时间（最常见原因）**：90% 的连接超时是由于电脑或手机系统时间误差超过 60 秒导致的。TLS 加密握手协议对时间戳校验极其严格，一旦时间不准会自动终止连接。打开系统设置，开启「自动与 Internet 时间服务器同步」；
2. **确认账号未欠费**：登录服务商官网后台，确认套餐是否已经开通生效，且当月可用流量未耗尽；
3. **强制更新订阅**：在客户端配置面板右键点击该订阅，选择「更新（Update）」，排查是否为本地订阅缓存了已废弃的旧节点地址；
4. **检查本地安全软件拦截**：暂时关闭 360 安全卫士、腾讯电脑管家或第三方杀毒软件，检查是否拦截了内核进程。

### Q2: 为什么开启代理后，国内软件（如微信、淘宝、网易云音乐）变得奇卡无比？
**A**: 因为你在客户端中错误地开启了 **「全局代理模式（Global Mode）」**。在全局模式下，你所有的国内流量都会被强制绕道境外的香港或日本机房转一圈再返回国内，导致延迟成倍飙升。**务必在客户端界面将模式切换为「规则（Rule）」**。在规则模式下，国内网站直连本地宽带，海外受限网站自动走代理通道，两者互不干扰。

### Q3: 为什么有的节点后面标着「0.5x」「1.0x」「3.0x」？这些数字是什么意思？
**A**: 这代表节点的 **流量计费倍率**：
- **1.0x（标准倍率）**：你实际消耗 1GB 流量，套餐扣除 1GB；
- **0.5x（优惠倍率）**：你实际消耗 1GB 流量，套餐仅扣除 0.5GB，适合用来大批量下载非关键大文件；
- **3.0x 或 5.0x（高倍率节点）**：你消耗 1GB 流量，套餐将瞬间扣除 3GB 或 5GB。高倍率通常出现在昂贵的 IPLC 专线或极度抢手的高纯净住宅节点上。新手使用时需留意倍率，避免流量意外耗尽。

### Q4: 苹果手机（iPhone/iPad）怎么下载 Shadowrocket（小火箭）？
**A**: 由于中国大陆区 App Store 的合规政策，Shadowrocket 无法在大陆区应用商店直接搜索下载：
1. 准备一个海外区域（如美区、港区、日区）的 Apple ID；
2. 在 iPhone 的 App Store 退出当前大陆账号，登录海外 Apple ID；
3. 搜索「Shadowrocket」（开发者为 Pan Guoqing，图标为浅蓝色底白色火箭，标价通常为 2.99 美元）；
4. 购买下载后，切回原本的大陆 Apple ID 即可，已安装的小火箭可长期正常使用与更新。

### Q5: 为什么安卓手机上代理客户端经常在后台被杀掉退出？
**A**: 国产安卓系统（MIUI/HyperOS、OriginOS、ColorOS、EMUI）的电池优化策略非常激进，会自动清理后台常驻进程。解决步骤：
1. 进入系统设置 $ightarrow$ 应用管理，找到代理客户端（如 Flclash 或 Clash Meta）；
2. 开启「允许应用自启动」与「允许关联启动」；
3. 将电池省电策略修改为 **「无限制（不进行后台限制）」**；
4. 在多任务后台界面，下拉客户端卡片并点击「加锁」小图标。

### Q6: 电脑连上代理后，在 Windows 终端（CMD / PowerShell）执行 `git clone` 依然卡死怎么回事？
**A**: Windows 系统的「系统代理」默认只接管具有图形界面的普通浏览器软件，默认不会接管控制台终端命令行。有两种完美的解决方案：
- **方案一（推荐，终极解法）**：在 Clash Verge Rev 客户端中开启 **TUN 虚拟网卡模式**，整机所有命令行的流量都会被内核强行捕获，无需任何终端配置；
- **方案二（手动设置环境变量）**：在 PowerShell 终端输入命令：
  `$env:all_proxy="http://127.0.0.1:7890"`，指定终端走本地混合端口。

### Q7: 免费公共转换网站（如订阅转换 API）安全吗？会不会泄露我的节点？
**A**: **存在严重的节点被盗取与泄露风险！** 第三方免费公开的订阅转换 API 网站，其服务器管理员完全可以在后台脚本中捕获你的原始订阅链接，将其存储在公开数据库中供他人白嫖，甚至将你的付费节点滥用于黑客攻击，导致你的账号因违反服务商 ToS 被直接封禁。建议：
1. 优先使用服务商官方后台直接提供的一键订阅链接；
2. 必须使用第三方转换时，推荐在本地电脑自行搭建离线 Subconverter 工具，绝不在公共转换站粘贴敏感订阅。

### Q8: 什么是「节点测速」中的 Ping 延迟与真实握手延迟？
**A**: 
- **ICMP Ping 延迟**：仅仅测试了你本地电脑到国内入口服务器的单程或往返物理距离（通常显示为极低的 5~20ms），完全不能代表你能否真正打开网页；
- **HTTP / TLS 真实握手延迟（Url-test）**：客户端真正通过入口专线、穿过海缆、到达境外落地机房、并向 Google 目标服务器发起一次完整的 TLS 握手测试（通常为 30~80ms）。评判节点优劣，必须以 **HTTP 真实握手延迟** 为准。

### Q9: 购买后如果觉得不好用，如何正确申请退款或维权？
**A**: 
1. 仔细查阅服务商官网底部的《服务条款（ToS）》中的退款细则，确认是否在允许退款的时效窗口内（通常为购买后 24~48 小时且流量消耗不超过一定比例）；
2. 登录官网用户后台，进入「工单支持（Support Ticket）」页面，新建工单，礼貌且清晰地陈述遇到的网络故障与退款诉求，附带测速截图；
3. 若遇到失联或诈骗恶意跑路，若使用支付宝/微信付款且在较短时间内，可尝试联系支付渠道进行交易风控争议投诉。

### Q10: 订阅链接更新频率设置多长时间最合适？
**A**: 推荐将客户端的订阅自动更新周期设置为 **24 小时（1天）至 48 小时（2天）**。更新太频繁（如每小时更新一次）会导致大量无意义的网络请求，甚至触发服务商后端的 API 防刷风控导致订阅被临时封锁；更新太慢（如数周不更新）则无法及时获取服务商新上线的高速备用节点。

### Q11: 路由器上配置了翻墙代理，为什么家里的电视盒子依然看不了 Netflix 4K？
**A**: 两个常见排查点：
1. **电视端未命中分流规则**：电视盒子内置的 Netflix App 域名列表极其庞大且包含复杂的 IPv6 地址。确认软路由分流规则是否已将 `netflix.com`、`nflxvideo.net` 等域名强制指定走解锁节点；
2. **IPv6 导致流量旁路泄漏**：国内运营商分配的公网 IPv6 地址可能会绕过软路由的 IPv4 代理通道直连公网，导致 Netflix 检测到来自大陆的 IPv6 地址从而拒绝播放。建议在软路由或电视盒子上关闭 IPv6 解析。

### Q12: 出现服务商官网打不开、订阅无法更新的「失联」状况，如何自救？
**A**: 请按照应急三步走：
1. 打开浏览器此前收藏的该品牌 **官方永久防失联发布页**，获取官方发布的最新镜像登录域名；
2. 查找该品牌的官方海外 Telegram 公告频道（通常订阅成功邮件或官网底部会附带），查看最新官方运维公告；
3. 如果全网域名彻底失效且超过 72 小时无公告，证明该品牌大概率发生跑路，应立即启动备用机场的订阅，并调整后续的选型策略（坚持月付，严选老牌）。
